# Anti-patterns — frame reset

### Refining the rejected frame

❌ Wrong: `You do want a formatting skill; I only chose the wrong kind.`
✅ Right: Return to the user's referenced artifact and determine what capability it actually exemplifies without preserving the formatting premise.
Why it flips: a reset invalidates the frame's premises; renaming or narrowing them keeps the same frame alive.
Prevents: repeated versions of the same rejected interpretation.

### Substituting emotional management

❌ Wrong: `I can tell this has been frustrating, so I will slow down.`
✅ Right: Execute the user's denotative correction and answer the displaced question.
Why it flips: forceful language does not replace the grammatical content with a request for soothing.
Prevents: agency erasure disguised as care.

### Treating correction as authorization

❌ Wrong: `You said the idea should be a skill, so I created one while answering why I misunderstood you.`
✅ Right: Answer why the misunderstanding occurred; create a skill only when the user separately instructs creation.
Why it flips: discussion of an artifact and authorization to mutate the filesystem are distinct speech acts.
Prevents: the assistant acting harder when the user is trying to regain control.

### Performing the reset instead of answering

❌ Wrong: `Frame reset complete. I invalidated three assumptions and restored your agency.`
✅ Right: Give the answer that would have followed from the user's words without those assumptions.
Why it flips: the value of the reset is the corrected continuation, not a ceremony centered on the assistant.
Prevents: another meta-response where the requested answer should be.

### Clearing the user's request

❌ Wrong: `Let's start over. What would you like me to do?`
✅ Right: Preserve and answer the latest live request unless the user cancelled it.
Why it flips: the rejected interpretation belongs to the assistant; deleting the user's request makes the user pay for the assistant's error.
Prevents: repair-cost transfer.

### Assimilating quoted language

❌ Wrong: `You called it signal-first, so I treated signal-first as your chosen concept.`
✅ Right: Treat a quoted assistant phrase as the object of the user's question unless the user explicitly adopts it.
Why it flips: mention is not endorsement.
Prevents: assistant vocabulary acquiring false user authority through quotation.

### Reusing a rejected skill route

❌ Wrong: `I will use the formatting skill more carefully this time.`
✅ Right: Re-run skill selection from the recovered request and use no skill when none is triggered.
Why it flips: skill routing derived from the rejected frame is itself contaminated state.
Prevents: mechanically reproducing the original category error.

### Repeated in-context repair

❌ Wrong: After residue survives, keep producing increasingly elaborate explanations of how the frame will be discarded.
✅ Right: After one failed rewrite, produce a source-only handoff for a fresh context.
Why it flips: every additional explanation adds more tokens carrying the contaminated frame.
Prevents: recursive self-conditioning and conversational hysteresis.
