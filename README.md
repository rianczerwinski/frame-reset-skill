# frame-reset

Recover the user’s actual request when an assistant-authored interpretation has displaced it.

## Use

> FRAME RESET. Return to my exact words and answer the question I asked.

The [skill instructions](SKILL.md) define the method and link its supporting references. Clone this repository as `frame-reset/` into your agent’s configured skill directory, preserving the complete folder. Discovery and invocation follow the host agent’s skill support.
